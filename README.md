# SENTINEL — Secure Code & Quality Guardian

A general-purpose agent skill for reviewing and improving software with equal emphasis on functional correctness, security, privacy, data integrity, regression prevention, reliability, performance, accessibility, and user impact.

## Files

- `SKILL.md` — Main skill definition and required workflow.

## Install / use

Add this repository or the `SKILL.md` file to the skills location supported by your coding agent. The skill is designed to be applied during feature work, bug fixes, refactoring, database/API changes, code reviews, and release preparation.

## Scope

Works across Flutter/Dart, Supabase/PostgreSQL, Next.js, React, TypeScript/JavaScript, APIs, backend services, and other software stacks. It adapts checks to the actual repository and available tooling.

## Important limitation

Sentinel is a review and engineering workflow, not a mathematical guarantee that software is defect-free or vulnerability-free. Its reports must state the exact scope of inspection and tests actually performed.
